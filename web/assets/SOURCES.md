# C++ Adventure visual asset sources

- `cat-crew-atlas.png` — original six-character cat adventurer illustration generated for C++ Adventure on 2026-11-14 with OpenAI image generation. No third-party image, meme, or character reference was used. The characters are Professor Cat, AI Teacher Cat, Hacker Cat, Debugger Cat, Wizard Cat, and Boss Cat. Local app asset; no internet needed at runtime.
- `cat-professor.png`, `cat-teacher.png`, `cat-hacker.png`, `cat-debugger.png`, `cat-wizard.png`, and `cat-boss.png` — lossless 512×512 RGBA crops from the corresponding non-overlapping 3×2 atlas cells. Alpha transparency is preserved; all six crops are separate local files so UI scaling cannot show a neighboring character. Each is used on the home crew card and its related lesson, AI settings, arena, lab, advanced C++, or RPG screen. No third-party image, meme, or character reference was used.
- `cat-companion.png` — original local companion illustration present before Stage 28.
- `coding-cats-room.png` — original local coding-room background present before Stage 28.
- `cpp-world-map.svg` — original local vector world map present before Stage 28.

No external stock image or meme is bundled. All listed assets are served from this folder for offline use.
